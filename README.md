# AI Resume Reviewer
AI-style resume reviewer for the assigned internship task.

## Features
- Resume upload/paste
- Resume score
- Section detection
- Role-specific skill matching
- Improvement suggestions
- Streamlit web UI

## Roles
Data Scientist, Software Developer, Electrical Engineer, AI/ML Engineer.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

This is a portfolio/learning prototype using local text-analysis heuristics; it does not guarantee hiring outcomes.
